# TC375 单电机上位机需求说明

版本：0.2  
状态：与下位机 MCU MVP 对齐

## 1. 产品范围

Motor Studio 用于 AURIX TC375 Lite 单电机控制器的研发、联调和数据
采集。当前只支持电机地址 `1` 和 MCU FOC 后端，不提供多电机协同，
也不提供 FPGA FOC 控制。

上位机通过原生 UART 协议 v2 与 FreeRTOS 固件通信。micro-ROS 和
Ethernet 属于后续阶段，不是当前上位机运行依赖。

## 2. 核心流程

1. 连接串口，或启动 TC375 单电机仿真器。
2. 自动读取设备信息和能力，确认协议 v2、单电机和 MCU 后端。
3. 完成电流与编码器校准，清除残余故障。
4. 选择转矩、速度或位置模式，填写 SI 单位目标。
5. 写入或读取电流环、速度环、位置环 PID。
6. 使能后观察实时波形、状态和告警。
7. 必要时保存参数；危险时使用紧急停止。

## 3. 已实现功能

### 3.1 波形与数据

- 单电机转速、电流、母线电压、温度和位置实时波形。
- 可添加、关闭和自动重新编号波形窗口。
- 每个窗口独立选择显示/隐藏信号、时间范围和 Y 轴范围。
- 暂停显示、清空缓存、CSV 实时记录和历史导出。
- 过流、过温、电压与状态字告警。

### 3.2 通信

- 串口枚举、常用波特率和后台异步收发。
- 协议 v2 帧解析、CRC16、拆包、粘包、噪声恢复。
- 连接后自动发送 `GET_DEVICE_INFO` 与 `GET_CAPABILITIES`。
- 每 250 ms 发送安静心跳，默认租约 750 ms。
- TX/RX 统计、十六进制日志和原始帧发送。
- 单电机仿真器可用于无硬件联调。

### 3.3 控制与维护

- 转矩 `N·m`、速度 `rad/s`、位置 `rad` 三种目标模式。
- 使能、失能和广播紧急停止。
- 电流环、速度环、位置环 PID 独立保存与读写。
- 全量校准、清除故障、参数保存、PING、设备信息和能力查询。
- 独立设备配置窗口：安全/运动限值、遥测频率、Flash 保存、恢复默认、
  控制后端和诊断信息。
- ACK/ERROR 与返回参数解析。

## 4. 共享协议

完整且唯一的协议定义位于：

[Native UART Protocol v2](../lower_computer/protocol/NATIVE_PROTOCOL_V2.md)

关键约束：

- 协议版本为 `0x02`。
- 唯一电机地址为 `0x01`。
- `0xFF` 只用于安全停止类广播。
- 多字节字段均为小端，浮点数为 IEEE-754 float32。
- 控制目标使用 SI 单位；遥测为兼容图表继续显示 rpm 与角度。
- v1 固件会被 v2 设备仿真器拒绝，不能静默混用。

## 5. 下一阶段

### P0：真实硬件联调

- 将命令与 TC375 UART DMA 驱动连接。
- 为请求加入 100 ms 超时、序号匹配、有限重试和错误码说明。
- 显示校准进度、故障明细、限值编辑和诊断信息。
- 根据真实功率板核对转矩常数、极对数、编码器方向和限值。

### P1：调试效率

- 参数批量读取、差异比较、Flash 保存确认。
- 阶跃、正反转、耐久等自动测试序列。
- 波形游标、缩放、峰值、RMS 和触发采集。
- CSV 回放、工程配置和测试报告。

### P2：后续平台

- Ethernet 传输与 micro-ROS 命令适配。
- FPGA 后端就绪后再开放后端选择和对应能力。
- 固件升级、用户权限、操作审计和 Windows 打包。

## 6. 验收

- Python 3.6 环境能够启动和通过自动测试。
- 仿真器只报告一台电机，协议版本为 v2。
- 连接后自动完成信息、能力和心跳交互。
- 三个 PID 环互不覆盖。
- 删除波形窗口后编号连续为 1..N。
- 随机拆包、粘包、CRC 错误后能恢复。
- 心跳中断后，下位机必须快速停止、失能并锁存通信故障。
- 真实设备的硬件过流、gate fault 和急停不依赖上位机。
